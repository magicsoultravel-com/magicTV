# Chromecast manual test checklist

Use Chrome with a Chromecast on the same network.

- [ ] Cast a live HLS stream — verify it loads on the TV.
- [ ] Pause/play from the cast row — controls are reflected on the TV.
- [ ] Change to another tile — the TV switches to the new stream.
- [ ] Toggle host PC audio/video in the cast popout — local player mutes/pauses and the local controls row appears/disappears.
- [ ] Control the local row independently from the cast row when both are visible.
- [ ] Disconnect — when the cast stops, local video restores to its pre-cast state.
- [ ] Refresh the page while casting — the app reconnects to the same session and highlights the active tile.
- [ ] Move the webpage volume slider — the TV volume changes; use the TV remote — the webpage slider updates.
